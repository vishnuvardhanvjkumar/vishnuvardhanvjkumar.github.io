About Me

My professional work spans technical communication, knowledge management, content operations, enterprise documentation and learning content. This portfolio demonstrates how those skills translate into structured technical documentation for engineering and manufacturing environments.

I work at the intersection of people, processes, systems and information. My experience includes creating and maintaining structured content, working with subject matter experts, managing knowledge repositories, supporting documentation lifecycles and translating complex information into clear, user-focused content.

My technical documentation interests include manufacturing work instructions, SOPs, product specifications, technical manuals, user guides, training content, release notes, knowledge articles and API documentation.

This portfolio contains independently created demonstration projects. The sample products, specifications and scenarios are fictional and are intended solely to demonstrate technical writing and documentation practices.
